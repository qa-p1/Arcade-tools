## Install or update

Download or update Arcade Tools from the [Arcade Tools releases](https://github.com/qa-p1/Arcade-tools/releases). Use Arcade Tools → Apps to install and update the other Arcade apps; see the [README](https://github.com/qa-p1/Arcade-tools/blob/main/README.md) for details.

## Works with other Arcade apps

Arcade Tools discovers and manages apps through Arcade Link. See the [Arcade Link specification](https://github.com/qa-p1/Arcade-Link/blob/main/SPEC.md) and the [Arcade Tools README](https://github.com/qa-p1/Arcade-tools/blob/main/README.md).

## Checksums
