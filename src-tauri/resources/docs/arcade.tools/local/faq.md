# Frequently asked questions

**Is Tools required?** No. Each Arcade app works and can be installed by hand.

**What happens when Tools quits or crashes?** App tray icons return when their hosting socket closes.

**Does closing the window quit Tools?** Closing destroys the webview. Tools remains resident while hosting or the cheat sheet is enabled. Use Quit Arcade Tools in the tray to exit.

**Can Tools edit window-manager shortcuts?** It reads desktop configuration and allows labels in its own settings. Only supported Arcade global shortcuts are rebindable.

**Does Tools upload diagnostics?** No. Create the ZIP locally, review it and attach it yourself to an issue.

**Why does a guide say local?** Unpublished documentation is bundled as a development snapshot; exact installed-version docs are fetched separately. Releases refresh snapshots from stable tags.
