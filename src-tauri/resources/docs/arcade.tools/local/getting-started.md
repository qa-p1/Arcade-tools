# Getting started

Download an installer from the [Tools releases](https://github.com/qa-p1/Arcade-tools/releases). Linux uses an AppImage; Windows uses a per-user NSIS installer; macOS uses a universal dmg. Run `arcade-tools --install --silent --no-launch` to integrate an AppImage, or drag the macOS app into Applications. Tools never changes shell profiles, quarantine, or SmartScreen settings.

Open Onboarding, choose apps or a bundle, review shortcut conflicts and tray/login preferences, then confirm installs. Existing manual or self-installed apps can be adopted; development builds are left in place. Open Learn for app guides.
