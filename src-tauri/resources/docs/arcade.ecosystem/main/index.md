# What Arcade is

Arcade is seven small desktop apps. Each is useful on its own, and they get
better together when you choose to connect them.

- **Arcade Box** — Run quick actions on files, media, and text.
- **Arcade Clipboard** — Keep clipboard history in sync across devices.
- **Arcade Find** — Find files by name or content.
- **Arcade Lens** — Select a screen area and act on it.
- **Arcade Look** — Preview files without opening another app.
- **Arcade Shelf** — Keep files and notes close while you work.
- **Arcade Wheel** — Launch apps and actions with a radial menu.

[Arcade Tools](installing.md) is an optional home for installing, updating,
launching, and removing the apps. Without Tools, each app still works by itself
and can be installed or updated from its own release page.

Arcade Link lets compatible apps offer each other useful actions on the same
computer. You decide which apps connect in each app's **Connected apps**
settings. Learn [how the apps connect](how-apps-connect.md), or read about
[privacy](privacy.md), [shortcuts](shortcuts.md), and [the tray icon](tray.md).
