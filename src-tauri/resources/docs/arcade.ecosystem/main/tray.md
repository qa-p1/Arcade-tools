# One tray icon

Arcade Tools can host the tray icons of running Arcade apps. Turn on
**Host Arcade app icons** in Tools to gather them under one Arcade icon.

Open the Arcade icon to see a submenu for each running app. Each submenu has
**Open**, **Settings**, app-specific actions when available (such as
Clipboard's **Private mode** or Find's **Rescan index**), **Restart**, and
**Quit**. The shared menu also has **Start all** and **Quit all**.

Turn on **Keep its own icon** for an app when you want that app to remain
separate. This setting is per app.

If Tools quits or crashes, each hosted app restores its own tray icon within a
second. Tools starts at login only while **Host Arcade app icons** is on. You
can turn hosting off and use the apps' own icons instead.

See [Installing and updating](installing.md) for setup, or the
[FAQ](faq.md) for troubleshooting.
